    How it works

    1. Paste. Text only for now, up to 5,000 characters per request. Longer text is split into parts automatically and rewritten piece by piece.
    2. Rewrite. Every sentence is rebuilt structurally, new words and new structure, not synonym swaps. Headings never change. Facts, numbers, dates, citations and tables stay identical in meaning.
    3. Check. A local detector estimate scores the result on rhythm and stock phrases, flags what still reads as AI-written, and a second pass rebuilds the flagged sentences. Maximum two passes: a third pass only shuffles flags without lowering the score.

    The engine is the HumanizeAnythingFully skill, running on the free NVIDIA model google/gemma-4-31b-it (fast, measured ~11s per rewrite). The skill's own default model, nvidia/nemotron-3-ultra-550b-a55b, is a reasoning model and too slow for a serverless call, so it stays the default in the MCP server instead. The same skill is free on GitHub for your own agent.

  -d '{"text": "Turmeric is a spice obtained from the rhizome of Curcuma longa.", "key": "nvapi-..."}'

    Limits: 5,000 characters per humanize request, 10 humanize calls per hour per address. Honest errors: 400 for empty or too-long text, 429 when rate limited, 502 when the model is unavailable.

    Honest limits

    • No method guarantees a detector score. Real human text is flagged 15 to 33 percent of the time by ZeroGPT. A score is a probability, never a verdict.
    • Simple factual writing, like school definitions, is statistically predictable no matter how it is phrased, and floors near 55 to 60 percent on ZeroGPT across five rewrite passes.
    • No plagiarism percentage is shown here. The local checker cannot run on serverless, and a fake number is never shown.
    • Never use this to disguise who wrote graded or academic work.
